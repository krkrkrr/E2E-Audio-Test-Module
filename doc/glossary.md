# 用語集

| 用語 | 意味 | 使わない言い方 |
|---|---|---|
| 録音（キャプチャ） | START から STOP までの間に USB Audio で受けたサンプル列を、加工せずにホストへ返すこと | 保存（デバイス内には貯めない） |
| 録音セッション | 1 回の START から STOP までの範囲 | |
| サンプル | 1 ch 分の 16 bit 符号付き整数値 1 個 | |
| 音声フレーム | 全 ch 分のサンプルの組。48 kHz / 2 ch なら 1 フレーム = 4 バイト | 「リンクフレーム」と区別する |
| 欠落 | ホストへ送るべきサンプルを、デバイス側で送れずに捨てたこと | ドロップ（口頭では可） |
| 複合デバイス | USB Audio と CDC ACM を 1 本の USB に並べたデバイス | |
| テストハーネス | ホスト上で録音を指示し、受け取り、検証する Python プログラム | |
| テスト対象アプリ | ホスト上で音を出し、RP2040 を出力先に選ぶアプリ | |
| キャプチャデバイス | RP2040 上のファーム。このリポジトリが作るシステム | |
| 位置 | 録音セッション内の音声フレームの通し番号（0 始まり）。欠落したフレームも番号を消費する | 連番（パケット単位の番号と区別する） |
| リンクフレーム | CDC 上でデバイスからハーネスへ送る、同期語と CRC 付きの単位（[ADR-0004](ADR/0004-frame-cdc-link-with-sync-and-crc.md)） | 「音声フレーム」と区別する |
| データチャンク | DATA リンクフレームの中身。先頭の位置と連続する音声フレーム列 | |
| 端数バイト | 音声パケットの末尾で 4 B に満たないバイト | |
| フィードバック値 | 受け入れたいレートを 10.14 固定小数点（kHz）でホストに伝える値。常に 48.0 | |
| ホスト制御値 | ホストが設定する音量とミュート。記録するが適用しない | |

## 単位

| 量 | 値 |
|---|---|
| サンプリング周波数 | 48,000 Hz |
| 量子化 | 16 bit 符号付き、リトルエンディアン |
| チャンネル数 | 2（L, R） |
| データ量 | 192,000 B/s（USB 1 ms あたり 192 B） |
